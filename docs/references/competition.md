# 제2회 TRAITHON 요약 (설계에 영향을 주는 규칙만)

- **주제**: 클릭베이트(낚시성 기사) + AI '운영'까지. 에이전트 AI가 어디까지 스스로 판단하고 언제 사람이 개입해야 하는지(인간 감독), 영향·위험 분석, 임계점의 근거가 핵심.
- **평가**: 전문가 85% (공식 제출물 + Evidence) + Peer Learning 15% (피어리뷰·그룹 멘토링 기여, Discord 공유, 발표 영상·현장 투표).
- **과정 중심**: TRY → OBSERVE → DECIDE → CHANGE 를 근거로 남긴다 → `docs/experiments/findings.md`.
- **모델**: A.X 4.0 Light 필수, 다른 모델은 병행 가능.
- **데이터**: AI-Hub 낚시성 기사(주), Webis Clickbait 2017(보조, Media 폴더 이미지 제외)만. 가공·증강 가능, 외부 데이터셋 추가 불가. 두 데이터셋 단순 병합 비권장. 재배포 금지.
- **Basekit 7개**: 1 영향평가 · 2 위험관리 · 3 투명성 · 4 데이터 · 5 모델 · 6 운영·모니터링 · 7 인간 감독 (예선은 1·2).
- **대시보드**: 구현 대신 와이어프레임·흐름도·호출 조건·증적 항목으로도 가능하지만, "왜 이 정보·조건·임계점인가"를 설명할 수 있어야 한다.

| Basekit | 이 저장소의 근거 |
|---|---|
| 1 영향평가 | 이해관계자(언론사·독자·판사), 접수 정책의 오탐 영향 — 대시보드·통계 |
| 2 위험관리 | 위증·지름길·프롬프트 주입·역할 붕괴·자동화 편향 — findings, 레드팀 |
| 3 투명성 | 근거 그래프, 에이전트 작업 기록(trace), 판결문 |
| 4 데이터 | `docs/references/dataset.md` |
| 5 모델 | `docs/references/a-x-model.md`, 스킬 버전 |
| 6 운영 | 작업 큐·대시보드·비용, 자율 범위 정책 |
| 7 인간 감독 | 판사 단계 H1~H5, 장부, 실험실 조건 A/B/C |
