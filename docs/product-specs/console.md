# 운영 콘솔 계약

앱 전체를 왼쪽 메뉴가 있는 운영 콘솔로 구성한다. 법정은 콘솔 안의 한 화면이다.

## 메뉴와 경로

| 묶음 | 메뉴 | 경로 | 내용 |
|---|---|---|---|
| | 대시보드 | `/` | 핵심 지표, 지금 작동 중인 에이전트, 최근 활동(장부 + 에이전트 이벤트), 바로 가기 |
| 재판 | 사건 접수 | `/cases` | 사건 목록, 약식 처리 / 재판 회부와 사유, 「재판 열기」 |
| | 법정 | `/court/:caseId` | 2D 법정, 판사 단계, 실시간 변론 |
| 에이전트 | 작업실 | `/agents` | 사무실 그림 위에 에이전트가 일하는 모습(방: 서기실 · 검사실 · 변호인실 · 재판연구관실 · 증거 검증실), 방마다 「업무 · 진행 · 확인」 수, 에이전트별 신뢰도 카드 |
| 규칙과 기록 | 규칙 · 온톨로지 | `/rules` | 온톨로지 그래프, 자율 범위 정책(약식 처리 기준 · 조치 단계), 스킬 버전 |
| | 감사 장부 | `/records/:caseId?` | 판결문, 사건별 근거 그래프, 장부 타임라인, 에이전트 작업 기록(trace) |
| | 통계 · 비용 | `/stats` | 신뢰도 통계 + 모델 호출 수 · 토큰 · 시간 |
| | 실험실 | `/lab` | 판사 판단 실험(조건 A/B/C), 레드팀 변형 |
| | 구현 현황 | `/progress` | 메뉴 맨 아래, 옅게 |

- 위 막대: 현재 메뉴 이름, 「AI 작동 중 n」 표시(작업이 있을 때), 판사 이름.
- 법정 화면 위에는 경로(「사건 접수 › 분야」)를 쓰지 않고 기사 제목만 쓴다.
- 3D는 제거한다.

## 새 API (api.md에 상세)

`GET /api/dashboard`, `GET /api/agents`, `GET /api/policy`, `PUT /api/policy`, `POST /api/intake`, `GET /api/jobs/{id}?since=n`(이벤트·중간 기록 포함).
