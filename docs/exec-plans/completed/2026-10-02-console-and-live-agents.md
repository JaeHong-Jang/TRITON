# 2차 계획 (완료): 운영 콘솔 · 실시간 에이전트 · 하네스 재구성

제품 책임자 피드백: 에이전트가 실제로 일하지 않음, 버튼을 여러 번 눌러야 함, 3D가 조잡함, 로봇 캐릭터 대신 사람, 온톨로지 그래프 없음, 운영 콘솔 필요, 1·2·3 탭/칩 미동작.

| 묶음 | 한 일 | 검증 |
|---|---|---|
| 에이전트 루프 | 계획 → 도구 → 초안 → 증거 검증관 → 고쳐 쓰기(≤2) → 제출/사람에게 넘김, 호출 ≤4, 이벤트·중간 기록, `publicText` | 백엔드 테스트, 실제 A.X 1·2·3심 |
| 접수·정책 | 서기 접수 검토 분리(`data/intake`), 자율 범위 정책 API | 정책 변경 시 약식/회부 재분류 테스트 |
| 법정 | 「재판 시작」 한 번 → 실시간 진행·자동 공개(건너뛰기), 항소·불일치 시 다음 심급 자동, 심급 탭·단계 칩, 사람 캐릭터 + AI 배지, 3D 제거 | 실제 서버 화면 흐름, 스크린샷 |
| 콘솔 | 왼쪽 메뉴 셸, 대시보드, 작업실(아이소메트릭 사무실), 규칙·온톨로지 그래프, 감사 장부 근거 그래프 | 실제 서버 스크린샷 |
| 리뷰 수정 | 재진입 시 장부 중복(HIGH), 첫인상 전 입장 힌트, 작업 우선순위, 빈 주장 제출, 겹침·잘림 등 | 재검증 통과 |
| 하네스 재구성 | `apps/` · `agents/` · `docs/{design-docs,product-specs,contracts,exec-plans,experiments,references}` · `tools/` · `.claude/{agents,skills,settings.json}`, 계층 검사, 편집 훅 | `tools/checks/verify.sh --ui` |
