# 옵시디언식 관계 그래프

## 목표
사용자 두 번째 이미지처럼 작은 점·얇은 선·간결한 라벨의 관계망으로 교체한다. 실제 데이터 수와 관계를 보존하고 기존 공개 정책/상세 연결을 유지한다.

## 디자인
- 단색 목탄 #211f1d, 원문 #dbd8cf, 검사 #cb785d, 변호 #7f9cbc, 검증 #8fac85, 사람 #d4b370, 규칙 #a092bc.
- Pretendard 라벨 11–12px, 기본 가벼운 회색, 선택·호버만 밝게.
- 상단 검색·간결한 조작, 펼치는 필터, 넓은 캔버스와 기존 상세 패널.
- 격자·군집 타원·도형 안 텍스트 삭제. 간선 기반 유한 force 배치, 실제 노드 수만 렌더.

## 소유와 검증
- obsidian_layout: lib/controlLayout.ts와 테스트, 연결 관계 배치와 안정성.
- root: GraphCanvas/CSS, 문서·브라우저 검증과 통합.
- 독립 리뷰: 별도 reviewer, 읽기 전용.
- 회귀: 연결 기반 위치·캐시·빈/소수·밀집 그래프, 기존 공개/상세 모델 테스트 유지. 실제 2노드/모의 연결 그래프와 390/1440px 캡처, 선택·이동·맞춤·확대·목록 확인.

## 구현 전 화면 판정
사용자 첫 이미지의 큰 다각형·고정 군집 타원·격자는 새 레퍼런스와 맞지 않는다. 재배치 및 캔버스 렌더를 교체한다. visual-verdict 스킬 부재로 직접 캡처와 독립 리뷰를 사용한다.

## 완료 결과
- 실제 간선 기반 유한 force 배치, 입력 순서 결정성, 기존 좌표 캐시 보존, 두 성분 좌우 배치. 격자·군집 타원·문서 도형을 제거했다.
- 작은 원형 노드, 연결 수에 따른 제한된 크기, 역할별 색, 얇은 선, 겹침을 줄인 라벨. 점과 라벨 선택, 인접 강조, 드래그·휠 확대·맞춤·검색·필터·목록·전체 보기 제공.
- 모바일은 라벨 수를 제한하고 소수 그래프의 이름은 유지한다. 공개된 실제 항목만 렌더하며 가짜 노드/간선을 추가하지 않았다. 새 의존성 없음.
