# 영역 법정 시각 개편

## 목표
주복사사를 참고한 애니메이션 법정: 검은 검증관, 천칭, 대치하는 단상, 주변 단두대 실루엣. 사람이 판결하고 첫인상 전 의견을 숨기는 기능 보존.

## 소유
- 주 에이전트: 배경·공통 팔레트·CourtStage·페이지 주변 표현·문서·통합 검증
- 캐릭터 담당: Person·Judge·Bench·Defendant2d SVG만
- 독립 리뷰: 변경 코드와 데스크톱/모바일 스크린샷 읽기

## 완료 기준
- 기존 기록 재생과 가려진 첫인상 화면의 시각 확인
- 키보드 근거 선택·역할 표기·동작 줄이기 유지
- 타입·빌드·기존 테스트·하네스 통과
- 생성 배경 저장 및 출처/프롬프트 기록

## 자산

`apps/frontend/public/art/domain-courtroom.png`: 내장 image_gen 생성. 최종 프롬프트와 출처는 같은 폴더 README.md. 애니메이션 분위기의 정적 배경이며 인물·명패·근거·천칭은 SVG 상태에 연결.

## 표현의 한계

모바일 작은 무대의 SVG 명패는 축소된다. 역할·근거·판결 조작은 HTML 패널에서 읽고 조작한다. 새 디자인의 사용자 사용성 평가는 아직 수행하지 않았다.
