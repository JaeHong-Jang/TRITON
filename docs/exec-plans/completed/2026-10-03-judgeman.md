# 저지맨 캐릭터 교체

## 목표와 범위
사용자가 지칭한 영역전개의 괴물인 식신 저지맨으로 기존 히구루마 인물 자산을 교체한다. 목재 법정과 재판 동작은 유지한다.

## 완료 기준
- 봉합된 눈의 흰 얼굴, 검은 천 형체와 천칭이 있는 저지맨 한 마리만 표시한다.
- 투명 자산을 프로젝트에 저장하고 대체 텍스트도 저지맨으로 갱신한다.
- 데스크톱과 모바일에서 캐릭터가 잘리지 않고, 첫인상 비공개 상태를 유지한다.
- 자동 검사·빌드 및 실제 8010 화면 반영을 확인한다.

## 작업과 소유
주 에이전트가 시각 계약, 생성 자산, CourtStage와 스타일 및 기록을 맡는다. 별도 리뷰어가 변경 범위와 화면 증거를 읽기 전용으로 검토한다. 백엔드와 사건 데이터는 변경하지 않는다.

## 검증 계획
기존 CourtStage 회귀 테스트의 단일 자산 기대값을 갱신하고 전체 verify.sh를 실행한다. 브라우저에서 생성 자산 로딩과 화면 크기별 배치를 확인한다. 실제 모델 호출은 이 변경의 검증 범위에 포함하지 않는다.
