# Pretendard 글꼴 통일

## 목표·소유·완료 기준
- 요청대로 전체 UI의 제목·본문·메뉴·입력창·법정/SVG 글자를 Pretendard로 통일한다.
- 주 에이전트가 공용 CSS·제목 컴포넌트·폰트 자산·문서를 소유한다. 기존 글자 크기·굵기·재판 동작은 유지한다.
- 공식 v1.3.9 가변 WOFF2와 OFL 라이선스를 앱에 포함한다. 실행 시 외부 CDN에 의존하지 않는다.
- 웹폰트 로드, 기본/제목/SVG 스타일, 좁은 화면 배치, 기존 검사와 독립 리뷰를 확인한다. 장식 변경을 복제하는 테스트는 추가하지 않는다.

## 검증 계획
- 첫 화면 검토: 본문에는 이름만 지정되고 폰트 파일이 없으며 제목은 명조체임을 확인했다.
- visual-verdict 스킬 부재로 직접 브라우저 확인과 독립 리뷰를 사용한다.
- 자동 검사와 브라우저 확인 후 완료 기록으로 이동한다.

## 완료·검증
- 공식 원본 가변 WOFF2 2,057,688바이트, OFL 원문과 출처를 `apps/frontend/public/fonts/pretendard/`에 포함했다. 패키지를 추가하지 않았다.
- `index.css`의 공용 토큰·웹폰트와 `index.html` preload 경로를 맞췄다. 공통 제목, 법정 CSS, SVG 글꼴 지정에서 명조/개별 글꼴을 제거했다.
- 실제 8010의 폰트 응답은 200·font/woff2이며 원본 자산과 바이트가 일치했다. 브라우저의 본문·제목·버튼·입력창·선택상자 계산 스타일 모두 Pretendard Variable을 우선 사용한다.
- 319px와 1440px 실제 사건 접수 화면에서 가로 넘침 없이 제목 줄바꿈과 버튼 배치를 확인했다. 화면 증거는 `.omx/artifacts/pretendard/`에 저장했다.
- `verify.sh`: 하네스 126파일 위반 0, 백엔드 173 통과·원천 표본 1개 건너뜀, 프론트 111 통과, 타입·빌드 통과. 독립 코드 리뷰 승인, 지적 0건.
- 글꼴 변경의 시각 검증이며 실제 모델 생성은 이번 범위에 포함하지 않았다. 사용자의 기본 브라우저 크기로 복원했다.
