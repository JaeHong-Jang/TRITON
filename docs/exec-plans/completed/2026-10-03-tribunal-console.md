# 콘솔 전체의 석조 법정 테마

## 목표와 완료 조건
- 사건 접수·대시보드·작업실과 공통 셸의 미래도시 배경을 제거하고 승인한 법정과 통일한다.
- 기사 등록·검색·필터·작업실 선택·판결과 공개 조건을 보존한다. 새 패키지는 추가하지 않는다.
- 실제 8010과 모의 화면에서 데스크톱/모바일 배치와 키보드 등록 폼 접근 확인, 기존 회귀·타입·빌드·하네스 및 독립 리뷰 통과.

## 시각 계획
- 석재 #e8e1d6, 종이 #f6f2ea, 먹색 #302923, 짙은 목재 #241d18, 황동 #8b7049, 밝은 금속 #dfbf8b.
- 본문은 기존 고딕, 주요 페이지/배너 제목은 법정과 같은 명조. 문서는 밝고 왼쪽 정렬, 사이드바는 어두운 목재색, 등록 버튼은 황동색.
- 배너 오른쪽에 기존 석조 법정 사진, 왼쪽에 읽기 쉬운 문구와 등록 동작. 중복 도시 표어와 기술 그리드 제거.
- 화면 구조: 메뉴 | 제목 → 법정 배너 → 상태·필터 → 사건 문서. 모바일은 메뉴 서랍과 세로 흐름 유지.
- 사용자가 승인한 법정 재료를 기준으로 선택했다. 새로운 미래도시 요소나 다른 시각 콘셉트를 추가하지 않는다.

## 소유
- 주 에이전트: index.css, console/ConsoleShell.tsx·console.css·parts.tsx, ui/styles.ts·Feedback.tsx, pages/DocketPage.tsx·DashboardPage.tsx, 문서·검증·기록.
- office_theme: console/office/OfficeMap.tsx·office.css, pages/AgentsPage.tsx만. 업무실 배경과 재질, 문구 변경.
- 독립 리뷰: 구현에 참여하지 않은 리뷰어가 코드와 화면 확인.

## 검증 범위
기존 자동 회귀를 이용한다. 장식 변경을 그대로 복제한 테스트는 추가하지 않는다. 모델이 없어 실제 A.X 생성은 검증 대상에서 제외한다. visual-verdict 스킬 부재로 직접 화면 검토와 독립 리뷰를 사용한다.

## 완료 결과 (2026-10-03)
- 공통 셸·색상 토큰·버튼·입력창을 석재·목재·황동·아이보리로 통일했다. 사건 접수와 대시보드 배너는 기존 석조 법정 자산을 재사용한다.
- 작업실의 도시 배경과 유리 단상을 석조 배경·목재·황동 재질로 바꿨다. 6개 역할 선택과 실제 작업 상태는 유지한다.
- 독립 코드 리뷰에서 문자열 치환으로 깨진 opacity 클래스가 발견돼 관련 세 곳을 수정했다. 최종 코드·화면 리뷰는 승인, 남은 지적 0건이다.
- `PATH="$PWD/.venv/bin:$PATH" bash tools/checks/verify.sh`: 하네스 126개 파일 위반 0, 백엔드 173개 통과·원천 표본 1개 건너뜀, 프론트 111개 통과, TypeScript·Vite 빌드 통과.
- 실제 8010과 모의 5292에서 1440/390px 화면, 검색, 등록 폼의 Enter·Tab 접근, 모바일 메뉴, 작업실 키보드 선택·지도 확대를 확인했다. 페이지 가로 넘침은 없다.
- 실제 사건의 첫인상 전 비공개 상태, 석조 배경·저지맨 자산과 모션 실행을 확인했다. 기사 등록·판결 데이터는 이번 확인에서 변경하지 않았다.
- 화면 증거: `.omx/artifacts/tribunal-console/`의 cases·dashboard·office 데스크톱/모바일 이미지. 시각 검토 기록: `.omx/state/tribunal-console/ralph-progress.json`.

## 검증 한계
- 실제 A.X 모델 생성은 모델 부재로 실행하지 않았다. 이번 변경은 화면 테마이며 모델 성능을 주장하지 않는다.
- 사용하지 않는 옛 장면과 역사 문서의 도시 자산은 보존했다. 현재 콘솔·페이지와 빌드된 JS/CSS에는 미래도시 자산 참조가 없다.
