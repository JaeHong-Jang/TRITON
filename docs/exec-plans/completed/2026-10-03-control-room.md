# 실행·근거·온톨로지 관제 작업실

## 목표와 완료 기준
기존 로봇·건물 작업실을 사건별 실행 제어, 실제 전이 파이프라인, 근거/온톨로지/연결 그래프, 상세·검증·이벤트 패널로 교체한다. 기존 법정·판결 절차는 유지한다. 새 패키지 없이 기존 React/SVG/API를 사용한다.

## 화면 계획
- 아이보리 #f6f2ea, 종이 #faf8f4, 목재 #241d18, 글자 #302923, 황동 #8b7049, 중앙 캔버스 #211d19, 캔버스 글자 #f1e7d3.
- Pretendard: 제목 26px, 본문 13–15px, 상태 12px. 데이터는 왼쪽 정렬, 숫자는 tabular-nums.
- 간결한 상단 사건 제어 → 수평 병렬/합류 절차 → 중앙 그래프+320px 상세 → 검증 셀 → 실행/사람 이벤트. 모바일은 세로 배치, SVG 영역만 이동.
- 중심 표현은 실제 관계선과 군집이다. 현재 승인된 법정의 재료색을 그래프에 적용하고, 건물·캐릭터·광고 배너를 삭제한다.
- 일반 카드 대시보드 대신 첫인상과 AI 준비의 합류, 근거→검증→사람 판단의 관계가 형태로 드러나게 한다.

- control_model: src/lib/controlGraph.ts 및 해당 테스트만. 공개 게이트·근거·온톨로지 모델.

## 검증
공개 전 데이터 차단, 실제 인용/보정 위치, 근거 판정 이력, 없는 관계 생성 금지, 레코드 변경 응답 섞임 방지, 제어 잠금에 의미 있는 회귀를 추가한다. 기존 전체 검사와 실제/모의 1440·390px 화면을 확인한다. 모델 부재 시 합성/모의 검증과 실제 생성 미검증을 구분한다. visual-verdict 스킬 부재로 직접 화면과 독립 리뷰를 기록한다.

## 완료 기록
- `/agents`의 로봇·건물 작업실을 사건별 실행 제어, 서버의 사건 절차, 내부 에이전트 루프, 근거·온톨로지·연결 그래프, 선택 상세, 검증 셀, 감사 로그로 교체했다. 기존 office 전용 5개 파일을 제거하고 법정에서 쓰는 공용 캐릭터는 유지했다.
- `controlGraph`는 실제 원문·제출 위치·코드 대조 결과·온톨로지 버전·사람 장부에 존재하는 관계만 만든다. 부재 주장의 대조 대상은 본문 전체이며 실제 발견 위치를 따로 표시한다. 최신 근거 판정은 장부 추가 순서와 판정 취소를 따른다.
- `controlSnapshot`은 사건·심급 불일치 응답과 첫인상 전 재판 기록을 차단한다. 비공개 API와 모의 서버는 claims/events/agentStats/calls/totals를 숨기고 공용 콘솔 집계도 보호한다.
- 서버 `controls`, `availableInstances`, 모델 health로 시작·재시도·취소를 제어한다. 시작/재시도 시 서버가 모델 연결을 다시 확인한다. 진행 중 중복 요청은 기존 jobId를 반환하며 실패·중단·완료 작업을 취소로 덮어쓸 수 없다.
- SVG 탐색은 검색·형태/상태/역할 필터·접기·확대/이동/맞춤·선택 중심·확대보기·키보드 목록을 제공한다. 노드와 관계 선택은 상세, 원문, 법정, 실제 식별자로 연결된 로그로 이어진다. 화면 밖 실행 모션과 숨김 탭 폴링을 중단한다.
- 실제 상태, 저장 기록 조회, 모의 시연을 구분한다. 저장 기록은 시간순 재생 기능으로 표현하지 않는다. 모델 미연결을 성공 상태로 표시하지 않는다.

## 검증 한계와 후속
- Ollama `ax4-light:q4_K_M` 연결이 없어 실제 모델 생성·GPU 처리량·모델 품질 및 `verify.sh --ui`의 A.X 시나리오는 미검증이다. 원천 데이터가 필요한 테스트 1개가 건너뛰어졌다.
- 132/260개 노드의 좌표 고유성·확장 범위는 단위 테스트로 확인했으나 대규모 브라우저 부하와 수천 노드 성능은 측정하지 않았다. 모바일에서는 필터·확대·목록 보기를 사용한다.
- 재시도는 기존 실행의 서버 계약을 따른다. 세밀한 시간순 로그 재생, 분산 작업 큐, 다중 사용자 인증은 이번 범위에 포함하지 않았다.
