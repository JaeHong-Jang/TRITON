# 석조 법정과 저지맨 모션

## 목표
사용자가 승인한 석조 원형 법정 3D 렌더 시안을 실제 법정에 적용하고 저지맨의 부유와 천칭의 독립 흔들림을 추가한다.

## 시각 계획
- 색: 석회석 `#a99a84`, 짙은 석재 `#393530`, 황동 `#b8955c`, 법복 `#161513`, 종이 `#f6f2ea`.
- 글꼴: 기존 법정 명조 제목과 본문 고딕 유지. 장면 안에 문자 자산을 굽지 않고 기존 HTML 안내를 유지한다.
- 배치: 왼쪽 넓은 장면은 채광창 → 저지맨 → 원형 바닥 중심에 정렬하고 오른쪽 사건 기록 패널을 유지한다. 모바일은 장면 다음 기록 패널 순서다.
- 특징: 승인된 기둥·원형 재판석·석조 바닥을 재사용하며 저지맨 하나를 여러 겹으로 움직인다. 새로운 메뉴 개편은 없다.
- 모션: 부유 8.5초, 천칭별 5.8·6.2·6.8초 주기, 그림자의 크기·농도 연동과 정적 채광. 장면 정지 버튼, 동작 줄이기, 숨겨진 문서 및 화면 밖 장면의 중단 제공. 모션은 근거 점수나 판결을 표현하지 않는다.

## 소유
- 주 에이전트: 계약·생성 자산·기록·브라우저 통합 검증.
- stone_motion: CourtStage, traditional-court.css, CourtStage.test 및 JudgemanFigure 컴포넌트.
- 독립 리뷰어: 코드와 실제 화면 읽기 전용 검토.

## 완료 기준과 검증
- 승인 시안과 일치하는 빈 석조 법정 배경 및 3D 저지맨이 한 마리 표시된다.
- 천칭/몸체 연결, 그림자, 반응형 경계가 자연스럽고 중복 천칭이 없다.
- 움직임 토글로 실제 CSS 모션이 정지/재개되고, 동작 줄이기 환경에서는 자동 중지된다.
- 첫인상 공개 경계, 기사 등록, 근거 선택, 사람 판결 동작을 보존한다.
- 기존 회귀 테스트·타입·빌드·하네스 검사, 실제 8010·모의 5292 데스크톱 및 모바일 확인.
- 결과는 생성 이미지와 CSS/SVG 레이어 애니메이션이다. 런타임 3D 메시나 실제 모델 실행을 구현했다고 표현하지 않는다.

## 완료 결과
- 승인 시안에서 빈 석조 법정과 투명 3D 렌더 저지맨을 분리 생성했다. 자산과 정확한 생성 프롬프트는 `apps/frontend/public/art/stone-tribunal-prompt.md`에 기록했다.
- 동일 캐릭터 이미지를 몸체와 세 천칭으로 나눴다. 몸체는 천칭 영역의 역마스크로 실루엣을 보존한다. 기존 재판 입력·상태 파생·첫인상 공개 경계를 유지했다.
- 전체 검사: 하네스 126개 파일 위반 0건, 백엔드 173개 통과·원천 표본 1개 건너뜀, 프론트 111개 통과, TypeScript·Vite 빌드 통과.
- 실제 8010의 1440px 화면에서 다섯 애니메이션의 실행, Enter로 정지·재개, 정지 상태의 transform 불변을 확인했다. 실제 319px와 모의 390px에서 가로 넘침 없이 캐릭터와 세 천칭을 표시한다.
- 모의 모바일 화면을 스크롤해 장면이 화면 밖에 있을 때 다섯 모션이 중단되고 돌아오면 재개되는 것을 확인했다. 첫인상 전 `data-disclosure=hidden`을 유지한다.
- 독립 코드·데스크톱·모바일 리뷰: SCOPE PASS, 지적 사항 0건. 별도 CourtStage 회귀 4개와 diff 검사 통과.
- 화면 증거: `.omx/artifacts/stone-tribunal/desktop.jpg`, `mobile.jpg`, `narrow.jpg`. 시각 검토 기록은 `.omx/state/stone-tribunal/ralph-progress.json`.

## 검증 한계
- `prefers-reduced-motion` 및 문서 숨김 처리는 코드와 CSS를 검토했다. OS 설정 변경·숨김 탭 전환에 의한 실제 중단은 별도로 시험하지 않았다.
- 실제 A.X 모델이 연결되지 않아 모델 생성과 `verify.sh --ui`는 실행하지 않았다. 기존 사건의 모델 오류 기록은 그대로 남는다.
- visual-verdict 스킬이 설치되어 있지 않아 직접 화면 검토와 독립 리뷰로 대체했다. ESLint 설정이 없어 별도 ESLint 검사는 실행할 수 없었고 저장소 하네스·타입 검사로 확인했다.
