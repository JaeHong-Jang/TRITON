# 미래도시 AI 법정 시각 기록

2026-10-03 전체 콘솔은 [석조 법정 공통 테마](../product-specs/console.md)로 대체되었다. 아래는 이전 시도의 기록이다.

2026-10-02 사용자 첨부 이미지의 역할별 공간, 흰색 로봇, 넓은 유리 타워 도시를 참고한다. 기존 어두운 영역 법정 및 작은 사무실 표현을 대체한다.

## 공간과 표현

- 브랜드는 TRITON / AI 법정. 남색 내비게이션, 밝은 청회색 바탕, 흰색 문서 패널, 청록색 주요 행동을 사용한다.
- 넓은 도시 파노라마와 구조적인 중앙 법정·연결 통로·여섯 업무 센터를 주 시각 요소로 사용한다. 장식용 도시를 실제 실행 그래프로 오인시키지 않는다.
- AI는 어두운 유리 얼굴과 역할별 조명을 가진 흰색 로봇으로 표시한다. 사람 판사는 사람으로 유지하며, 신문 피고의 눈·팔·다리를 유지한다.
- 법정은 높은 유리 천장, 층이 구분된 법대, 대칭 변론 단상, 중앙 증거 천칭으로 구성한다. 이전 단두대·공포 형상은 제거한다.
- 작업실의 여섯 센터는 서기·검사·변호인·반대신문·재판연구관·코드 검증이다. 실제 API의 working, queued, currentTask만 현재 작업 상태의 근거로 사용한다.
- 로봇 그림은 공용 ui/RobotAvatar.tsx에 두고 법정·작업실에서 재사용한다. 고정 기준점은 발 위치 (0, 0), 대략 x ±60, y -200~0이며 tone, variant, working, label을 받는다.
- 저작권 표시가 있는 참조 이미지는 직접 자산으로 복사하지 않는다. 새로 생성한 배경의 프롬프트와 경로를 기록한다.

## 사용자 흐름과 보호 조건

- 메뉴의 사건 접수·법정·작업실·규칙·기록·통계·실험실·구현 현황을 유지한다.
- 사건 접수의 새 기사 등록 → 제목·본문 입력 → 등록 → 법정 이동을 유지한다.
- 첫인상 이전 AI 주장·권고·천칭 비공개, 최종 판결 이전 정답 비공개는 기존 계약을 따른다.
- 실제 실행·저장 기록·모의 시연 표시를 유지한다. 장식용 건물 조명은 모델 연결·작업 성공을 뜻하지 않는다.
- 판결·항소·근거 채택은 기존 기능 그대로이며 이 변경은 API와 재판 전이를 바꾸지 않는다.
- 모바일에서도 메뉴·등록·근거 검토·판결 버튼을 사용할 수 있어야 한다. 그래픽은 축소하거나 별도 가로 스크롤하며 페이지 전체 가로 넘침은 허용하지 않는다.
- 명확한 대비, 키보드 포커스, 버튼 이름, reduced-motion을 유지한다. 배경 로딩 실패 시에도 조작과 역할이 남는다.

## 검증

타입·빌드·회귀 테스트와 독립 코드/화면 리뷰. 데스크톱·모바일에서 대시보드, 사건 접수, 작업실, 법정 확인. 실제 모델 미연결 상태를 성공으로 표현하지 않는다.
