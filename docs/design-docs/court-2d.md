# 2D 법정 계약

SVG 일러스트 법정만 쓴다. 3D(react-three-fiber)는 제거한다.

## 콘셉트

- 모든 인물은 **작고 귀여운 사람 캐릭터**(둥근 머리, 머리카락, 단순한 옷, 2~3단 명암 — 사용자가 보낸 사무실 일러스트 같은 그림체). 로봇은 쓰지 않는다.
- **AI 에이전트는 사람 모습 + 「AI」 배지**(가슴 명찰과 머리 위 작은 칩), **판사는 배지 없는 사람**. 화면만 봐도 "AI는 변론하고 사람이 판결한다"가 읽혀야 한다.
- 같은 그림체를 법정(정면)과 작업실(위에서 비스듬히 본 사무실)에서 함께 쓴다.
- 피고는 **눈·팔·다리가 달린 신문** 캐릭터. 1면에 재판 중인 제목이 인쇄되어 있다.
- 정면에서 본 무대 단면 일러스트 (16:9, `viewBox="0 0 1600 900"`), 깔끔한 플랫 일러스트 + 2~3단 명암, 외곽선 없이 면으로 표현.

## 배치

| 위치 | 요소 |
|---|---|
| 위 가운데 | 법대(판사석 3석). 심급에 따라 켜진 판사석에만 사람 판사(검은 법복, 성별 중립 실루엣)와 「판사석 n · 사람」 명패 |
| 가운데 | 놋쇠 천칭. 왼쪽 접시 찬성(낚시성이다), 오른쪽 접시 반대(낚시성 아니다) |
| 왼쪽 | 검사석, 검사 에이전트 1~3명 (AI 배지) |
| 오른쪽 | 변호석, 변호 에이전트 1~3명 (AI 배지), 그 옆에 피고 신문 |
| 앞 가운데 | 증거 제출대 (선택한 근거 표시). 1심 서기, 3심 재판연구관(둘 다 AI 배지)은 법대 앞 |
| 아래 | 방청석 난간 |

## 표현 규칙

- 색: 나무 `#6b3f22`·`#8a5a35`·`#a87447`, 벽 `#f3ead8`, 놋쇠 `#c9a227`, 찬성 `#c2410c`, 반대 `#1d4ed8`, 서기·연구관 `#15803d`, 먹 `#1c1917`.
- 역할 복장: 검사 짙은 정장 + 주황 넥타이·배지, 변호인 짙은 남색 정장 + 파랑 넥타이, 서기 초록 조끼·메모장, 재판연구관 안경·책, 판사 검은 법복. 이름표 「검사 A · AI」.
- 대기 중: 숨쉬듯 아주 작게 움직임. 발언 중: 살짝 들썩임 + 말풍선(주장 유형 + 주장 앞부분). 작업 중(에이전트 루프): 머리 위 활동 말풍선에 이벤트 문구(예: "15번 문장 확인 중", "위증 의심 → 다시 작성") + 타자 점.
- 방청석: 난간에 잘린 머리만 떠 있지 않게, 난간 뒤 의자에 앉은 전신(상반신) 인물로 그리거나 없앤다.
- 천칭: 기울기는 계산식 그대로 (`balance.tilt`, 양수 = 왼쪽 내려감), 부드러운 전환. 접시는 항상 수평으로 매달림.
- 근거 추: 근거 하나 = 추 하나, 채움은 입장 색, 테두리는 근거를 낸 에이전트 색. `#15` 또는 `부재` 표시. 접시당 최대 8개, 나머지는 `+n`. 새 추는 떨어지며 들어오고, 절반이면 `½`, 무효(위증·기각·증거 아님)는 회색 ✕로 받침대 옆 바닥에 쌓인다. 클릭·Enter로 해당 근거에 초점.
- 접시 아래 범례: 「◀ 찬성 · 낚시성이다 17.5」, 「반대 · 낚시성 아니다 16 ▶」 (색만으로 구분하지 않음).
- 첫인상(H1) 전: 천칭에 천을 덮고 「첫인상 기록 전 · 천칭 가림」.
- 판결 후 피고: 무죄면 깡충, 유죄면 낚싯바늘이 내려와 걸림, 항소 중이면 「?」. 재판 중에는 표정 변화 없음 (판사에게 힌트를 주지 않기 위함).
- 폭 600px 미만: 전문 분야·증거 제출대 문구 숨김, 범례와 추 번호는 유지.
- `prefers-reduced-motion`이면 애니메이션 끔.

## 연결

- 입력은 기존 `SceneView`(`scene/CourtScene.tsx`)를 그대로 쓰고, 필요한 값(발언 중인 주장, 생성 중인 에이전트)은 `features/court/view.ts`에서 파생해 추가한다.
- 기본 번들에 three.js가 들어가지 않아야 한다 (3D는 `React.lazy`).
