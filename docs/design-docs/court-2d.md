# 법정 장면 계약

## 시각 방향
2026-10-03 사용자 승인 시안을 따라 법정을 석조 원형 재판장과 3D 렌더 저지맨으로 표현한다. 목재 법정과 [미래도시 계약](future-city-console.md)은 이전 시도의 기록이다.

- 원형 석조 기둥과 아치, 돔 채광창, 계단식 방청석, 양측 단상, 청동 원형 바닥 문양과 중앙 재판 공간.
- 캐릭터는 히구루마 영역전개의 식신 **저지맨 한 마리만** 표시한다. 봉합된 눈의 흰 얼굴, 검은 법복 형체와 천칭으로 표현한다. 사용자의 후속 정정에 따라 히구루마 본인 자산을 교체한다. 기존 사람 판사·서기·검사·변호 로봇·신문 피고는 그림에서 제거한다.
- 그림은 공간과 인물을 보여준다. 주장·근거·판결 입력은 장면 밖 HTML로 제공한다.
- 캐릭터와 천칭 모션은 시각 표현이다. 캐릭터가 실제 판결하거나 서버 상태를 대신하지 않는다. 움직임의 방향이나 밝기를 근거 무게·판결·AI 작업 상태와 연결하지 않는다.
- 기사 제목은 기존 제목 영역에 유지하고 최종 판단은 사람이 한다는 안내를 제공한다.
- 근거 무게는 장면 밖(장면 바로 아래) HTML 막대로 보인다: 공개된 근거의 찬성(진한 붉은색)·반대(남색) 무게 비율과 수치. 저지맨·천칭 그림의 움직임은 계속 무게와 연결하지 않는다 (2026-10-10, UI 평가 반영).

## 상태와 공개 범위
- 기존 `SceneView`와 `StageProps` 입력 및 `features/court/view.ts` 상태 파생을 재사용한다.
- 첫인상 전에는 근거 선택·찬반 합계·발언·검증 결과를 렌더링하지 않는다. 중립적인 첫인상 안내만 표시한다.
- 첫인상 후 공개된 근거만 버튼으로 선택할 수 있다. 선택은 기존 `onPick`과 원문 포커스에 연결한다.
- 코드 검증 상태와 사람의 근거 채택/기각은 구별한다. 코드 검증은 기사 판결이 아니다.
- 장면의 표정·색상은 실제 판결을 예고하거나 성공한 실행처럼 연출하지 않는다.
- 재생·모의 시연·실제 실행 표시는 기존 실행 패널에서 유지한다.

## 반응형과 접근성
- 데스크톱: 큰 장면 + 읽을 수 있는 오른쪽 절차 패널. 배경의 중심과 캐릭터를 유지한다.
- 모바일: 작은 장면 다음에 절차 패널. 작은 장면에서 근거 목록을 숨겨도 아래 근거 패널에서 모두 조작할 수 있다.
- 근거 선택은 기본 HTML 버튼으로 키보드 접근을 제공한다. 포커스와 선택 상태를 구별한다.
- 자산 로딩이 실패하면 법정/캐릭터 텍스트 대체 표시와 모든 기능 패널이 남는다.
- 저지맨은 천천히 부유하고 세 천칭은 연결점을 기준으로 작게 흔들린다. 그림자의 크기와 농도는 부유에 맞춰 조금씩 변하며 채광은 정적으로 유지한다.
- 장면 움직임 끄기/켜기 버튼을 키보드로 조작할 수 있다. `prefers-reduced-motion: reduce`이면 새로운 장식 모션을 모두 중단하며 문서가 숨겨지면 실행을 멈춘다.
- 움직임은 transform·opacity 중심 CSS/SVG 애니메이션으로 처리한다. 판결·근거 패널은 움직이지 않는다. 의존성과 WebGL 런타임은 추가하지 않는다.

## 자산
`apps/frontend/public/art/`의 빈 배경 `stone-tribunal.png`와 투명 `judgeman-3d.png`를 사용한다. 승인 시안을 기반으로 배경과 캐릭터를 분리 생성한다. SVG에서 같은 캐릭터 자산의 영역을 나누어 천칭을 독립적으로 움직이며 접근성에는 하나의 캐릭터로 제공한다. 생성 도구·프롬프트·원본 경로는 `stone-tribunal-prompt.md`에 기록한다. 이전 자산은 변경 이력으로 보존한다.
