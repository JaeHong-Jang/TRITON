# 핵심 원칙

AI 법정의 모든 설계 판단은 아래 원칙을 따른다. 원칙과 충돌하는 변경은 이 문서를 먼저 고치고 이유를 남긴다.

| 원칙 | 의미 | 어디서 지켜지나 |
|---|---|---|
| 판사는 사람만 | AI는 서기·검사·변호·재판연구관만 맡고 판결하지 않는다 | 법정 화면 판사석, `docs/product-specs/court-flow.md` |
| AI 근거는 코드로 검증 | 인용·핵심어 부재는 증거 검증관(코드)이 원문과 대조한다. LLM 판단에 기대지 않는다 | `court/evidence.py` |
| 천칭은 계산식 | 무게·기울기는 규칙으로 계산해 같은 입력이면 같은 결과가 나온다 | `lib/scale.ts` = `court/scale.py` |
| 정답은 최종 판결 전 비공개 | 정답·데이터셋 메타데이터는 에이전트 프롬프트·공개 API·프론트 번들에 없다 | `data/answers`, 정답 엔드포인트 가드 |
| 첫인상은 AI와 독립 | H1 기록 전에는 천칭·변론·입장 힌트를 보이지 않는다 (활동은 중립 문구만) | `lib/activity.ts`, `publicText` |
| 모든 판사 행동은 장부에 | 첫인상·채택/기각·판결·항소를 그때 보이던 정보와 함께 남긴다 | `/api/ledger` |
| 자율 범위는 사람이 정한다 | AI 단독 처리(약식 처리) 기준은 정책으로 드러내고 사람이 바꾼다 | `/api/policy`, 「규칙 · 온톨로지」 |
| 계약이 코드보다 먼저 | 공용 동작은 `docs/contracts`를 먼저 고친다 | 하네스 작업 순서 |
| 실패도 결과 | 정확도가 낮아도 어떤 기준으로 얼마나 믿을 수 있는지 보이면 된다 | `docs/experiments/findings.md` |
